Yeh browser USB flashing support nahi karta. Computer par Chrome ya Edge mein kholiye. Page https:// par khulna chahiye, tabhi install hoga. Chip apne aap pehchana jayega

Kaise karein

  1. Device ko data wali USB cable se computer se jodiye.
  2. Install firmware dabaiye aur list mein se device ka port chuniye (CP210x / CH340 / USB JTAG).
  3. Pehli baar install kar rahe hain to Erase wala option chuniye. Update ke liye erase zaroori nahi.
  4. 2–3 minute rukiye. Beech mein cable mat nikaliye.
  5. Install ke baad device WiFi hotspot banayega. Phone se us hotspot se judkar apna WiFi naam aur password daaliye.

Port nahi dikh raha?

  1. Cable badal kar dekhiye. Kai cable sirf charging wali hoti hain.
  2. USB driver install kariye: CP210x ya CH340.
  3. Phir bhi na ho to device ka BOOT button dabaye rakhiye, RST/EN ek baar dabaiye, phir BOOT chhodiye aur dobara Install dabaiye.
